# **App Name**: EchoVerse

## Core Features:

- Enhanced Text Chat Interface: Implement a user-friendly interface for text input and displaying character responses.
- User Ratings & Reviews: Develop an interface for rating characters and viewing average ratings on character profiles.
- Account Notification Management: Allow users to adjust their notification preferences within their account settings.

## Style Guidelines:

- Primary color: Dark teal (#008080) for a sophisticated and calming feel.
- Secondary color: Light gray (#F0F0F0) for backgrounds to provide contrast.
- Accent: Coral (#FF7F50) to highlight interactive elements and calls to action.
- Clean and modern typography for readability and a polished look.
- Use minimalistic icons for clear navigation and easy understanding.
- A clean and responsive layout that adapts well to different screen sizes.
